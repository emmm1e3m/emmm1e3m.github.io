# 旅行饼狗开发纲要

## 目标

复刻《旅行青蛙》的陪伴与离线收集感，制作完整、美观、有趣且自洽的粉丝向网页游戏“旅行饼狗”，部署到 [emmm1e3m.github.io](https://github.com/emmm1e3m/emmm1e3m.github.io)。

游戏本体固定在：

```text
/AllForSUXINHAO/TravellingBingo/
```

根首页只增加跳转入口；`AllForSUXINHAO/` 只保留 `TravellingBingo/`。

## 关于饼狗

### 概述

![饼狗形象参考](../../resources/raw/travelling-bingo/references/outline/image.png)

饼狗是 TOP 登陆少年组合成员苏新皓的卡通形象，是一只喜欢吃苹果、戴着苹果头套的小狗。信号灯是已经确定的粉丝名；C 位、唯一 ACE 与公司打压等叙事按本项目既定事实口径表达。

饼狗不是无条件执行指令的按钮。它会分别决定是否想旅行、做电脑活动或弹琴；刷播和冲热共享电脑意愿。不想做的事应保留入口但视觉变淡，点击后给出温和拒绝，不扣资源。睡一觉可以刷新意愿。

### 住所

![铲铲饼屋参考](../../resources/raw/travelling-bingo/references/outline/image-1.png)

房间严格以这张 `image-1.png` 为唯一构图母版，不改变绘画风格、竖版比例、两层结构、树冠、人物、兔子装饰或家具位置。

- 床铺：饼狗睡觉的地方；睡觉时角色必须准确落在床上。
- 电脑：刷播与冲热的位置。
- 衣架：换装小游戏“奇迹饼狗”，正文为“什么样的搭配最合适呢？”。
- 电子琴：覆盖两个八度，可以真实弹奏；弹琴本身也是读条活动。
- 唱片机：从百万直拍收藏夹锁定的最新页曲目中选择 B 站视频内嵌播放。
- 冰箱：使用 🍎 补充活动道具；金额显示为 `N🍎`。
- 收藏墙：展示明信片、百万直拍、全站第一和已经遇见的好朋友。
- 房门：开始旅行；饼狗出门后房间中不显示角色。
- 问号：介绍房间设施、读条，以及 🍎 的获得与花费。

待机时点击空白收起信息栏并展开房屋；点击设施后房屋收窄、左移，右侧出现与顶栏对齐的信息栏。

## 技术与运行边界

- 使用适合静态部署的技术栈，但游戏本体不依赖游戏后端、账号、登录、数据库或运行时收藏夹 API。
- 本地游玩通过一键启动脚本进入；线上部署到 GitHub Pages 子路径。
- 需要 B 站内容时，构建期保存 BVID、标题、作者、发布时间和海报映射；运行时使用 B 站 iframe 播放器，不跨域抓取收藏夹。
- 图标优先使用 emoji、文字或项目内图形资源；确有必要的角色与房间素材可使用 ImageGen，真实收藏不使用生成图代替。
- 所有用户提供或指定的素材均视为已有授权。

## V3 存档

- 每次打开页面由用户新建旅程或手动选择 `.bingo`；离开房间时先请求下载最新存档，玩家确认已经保存且期间没有新进度后才回标题页。
- PWA 更新和跨标签接管不得绕过同一存档确认流程自动刷新未保存的游戏。
- V3 业务状态记录用户名、陪伴天数、🍎、道具、收藏、好友、当前三条任务、活动意愿、调试配置、随机序列和进行中活动。
- 进行中活动必须保存原始 `startedAt`、`endsAt` 与奖励计划；之后即使默认时长延长，旧活动仍按开始时的绝对 `endsAt` 恢复和完成。
- 导入旧 V1/V2 档时先校验原文件完整性，再迁移到 V3；迁移不得重抽已开始活动。
- 存档不保存收藏总数、下一个全站第一索引或分类解锁列表。目录新增后，旧档自然把新 ID 视为未拥有。
- 不维护预制全收集存档。DEBUG 提供“一键全收集”，按当前目录即时生成。
- 连续激活大标题五次后输入 `TravellingBingo` 解锁 DEBUG；DEBUG 可调整未来活动时长与概率，但不强制饼狗对所有事情感兴趣。

## V3 游玩规则

- 旅行、刷播、冲热、弹琴、睡觉五类活动都是默认 112 秒的读条任务，开始前均在信息栏二次确认。
- 每次成功领取读条结果后，陪伴天数增加一天；普通房间操作不增加天数。
- 五类活动都可以取消。取消不增加天数，开始时已经消耗的补给或幸运苹果不返还。
- 睡觉完成后得到 1🍎，刷新饼狗意愿，并播放房间整体变暗再变亮的日夜交替。
- 旅行先判朋友再判明信片；朋友与明信片不能同时出现。
- 房间中的三条 Bingo 小任务是常规 🍎 来源；每条完成立即奖励，整板完成后显示 `Bingo!` 并刷新三条。
- 所有货币可见文案统一使用 `N🍎`，不使用“X 个苹果”“苹果只在游戏里流通”等出戏表述。
- 收藏墙未全收集时不显示总数、百分比、灰色卡或未解锁类别；第一次获得对应内容时才解锁分类。
