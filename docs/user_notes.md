# 旅行饼狗使用说明

## V4 的核心规则

- 新开始的旅行、刷播、冲热、弹琴和睡觉默认读条均为 1 分 12 秒，开始前会在右侧信息栏二次确认。
- 五类饼屋活动每成功领取一次，或苹果钟首次到点完成一轮，陪伴天数增加一天。提前取消、重复检查、普通现实停留结算和待办操作不会进入下一天；活动取消也不会返还已经消耗的补给或幸运苹果。
- 存档会记录正在进行的活动及其绝对开始、结束时间和奖励计划。即使以后再次修改默认时长，旧任务仍按开始时写入的时间完成。
- 饼狗对旅行、电脑和音乐分别有自己的意愿；刷播与冲热共享电脑意愿。它不想做的入口会变暗，点击只显示原因，不会偷偷开始或扣资源。
- 点击房间空白会显示当前任务和饼狗兴趣概览；信息栏右上角可收起。活动中左下 `↩️` 会打开真正的取消确认，右上 `ℹ️` 打开简洁的“铲铲饼屋的小纸条”；详细价格仍在冰箱查看。

## 冰箱与两种魔法

冰箱共有七种带 emoji 的道具，金额统一显示为 `N🍎`：

- 🍱普通旅行便当、🍎苹果旅行便当、🎧信号耳机、🧰热度工具箱和 🍀幸运苹果；
- ⚡瓶装速度魔法：读条仍在进行时可消耗一瓶，让这次活动立刻进入可领取状态；
- ✨瓶装活力魔法：让饼狗接下来七个相伴日对旅行、电脑和音乐都有兴趣。

七个相伴日会由成功领取饼屋活动或完成苹果钟推进，不是七个自然日。苹果钟推进到第七天时，活力效果结束并恢复饼狗当日偏好。魔法不需要时不会被消耗。

## 收藏与好朋友

- 明信片和百万直拍随机从未拥有项中选择，不会重复；全站第一按 Dynamite → Talk WORTHY? Talk DIRTY! → Make A Wish → Dawn in my soul → 愿与愁 → 囍 → Hey Mama → POWER 的时间顺序获得。
- 旅行遇见朋友时不会同时得到明信片。弹琴只会召回已经认识的朋友，不会凭空解锁新朋友。
- 收藏墙只展示已经获得的明信片、百万直拍、全站第一和好友。没有内容时显示“惊喜会在相遇时悄悄出现。”
- 缩略图与详情图会铺满裁切；在详情中点击图片，可以进入完整比例的全屏查看并下载到本地。
- DEBUG 的“一键全收集”包含好友，“一键撤销全部收集”会同时清空收藏与好友记录；无需维护专用全收集存档。

存档不写死当前收藏或好友总数，也不保存分类解锁状态。以后增加内容时，旧存档会把新增 ID 视为尚未获得的内容。

## 房间、电子琴与播放器

- 房间严格使用用户提供的 1098 × 1433 透明原图，网页不重绘、不裁切，只生成等比无损 WebP。饼狗在床、两台电脑、衣架、电子琴、冰箱、唱片机、收藏墙和房门的位置都按原图像素坐标锁定。
- 电子琴有 C4–B6 三个完整八度，共 36 个半音，分三排显示；中间一排的 C 是 C5。鼠标、触摸可以弹全部琴键，物理键盘只映射白键。
- 唱片机与收藏详情共用一个持久播放器。选曲或打开视频详情会立即向 B 站播放器请求自动播放；收起信息栏或切换维度后 iframe 仍保留，也可以明确停止并关闭。
- 唱片机可以在“百万直拍精选”和自己的播放列表间切换。输入列表名称，再按一行一个填写 BV 号或完整 Bilibili 视频链接，即可创建或更新曲库；重复 BV 会自动去重。
- 播放器保存当前 BV、播放列表、主动设置的起播秒数和列表/单曲/随机模式。B 站 iframe 受跨域与浏览器自动播放策略限制，网页无法确认真实播放、暂停、进度或结束，也不能可靠在视频结束时自动续播。

## 现实生活维度

房间右下角可以切换维度：

- 二楼电脑“数据”页说明如何在该页面开始刷播或冲热，并提供运行组入口；具体操作步骤目前仍是待后续补充的占位说明。
- 一楼电脑“工作”页提供 5、25、50 分钟苹果钟、已解锁明信片背景和待办清单。待办可以创建、修改、标记完成、恢复未完成和删除，并随存档保存。
- 苹果钟按绝对结束时间完成；首次到点完成会增加一天陪伴天数，重复检查、未到点或提前取消不加天。允许通知后，时间到会请求浏览器系统提醒；若通知不可用或未授权，会使用页内提示。
- 每在现实维度停留完整 10 分钟，结算基数增加 1🍎。返回游戏时，选择“是的🥰”获得全额，选择“没有🥺”获得向下取整的一半；现实停留结算和待办操作本身都不增加陪伴天数。

## 存档兼容与浏览器限制

- 新存档为 V4；读取时严格支持 V1、V2、V3 和 V4。系统先校验原文件摘要，再迁移和核对当前目录，不会先改文件再验摘要。
- V4 存档包含当前活动、两种魔法、现实停留与待结算奖励、待办、苹果钟和播放器设置；不会复制海报、视频元数据或收藏目录总数。
- 标题页和房间都提供“检查新布置”，它会请求 Service Worker 检查更新，但不会跳过未保存进度保护直接刷新。
- 守候音频是一个可暂停的 10 Hz、音量 0.01 的低频正弦波，只在开始或确认导入旅程的用户手势后启动。它只能尽量减少浏览器休眠，不能绕过系统节能和后台冻结。
- 系统通知需要用户主动授权。页面完全关闭、浏览器被冻结或设备休眠时，不保证准时弹出；返回页面后会按绝对时间补检查。
- B 站有声自动播放也可能被浏览器拦截，需要在播放器中再次操作。

## 本地启动与验证

Windows 下双击仓库根目录的 `启动旅行饼狗.cmd`，或运行：

```powershell
npm ci
npm run dev -- --host localhost --port 5173 --strictPort --open "/AllForSUXINHAO/TravellingBingo/"
```

完整本地门禁：

```powershell
npm run verify
npm run build
npm run site:assemble
npm run site:verify
npm run test:e2e
```

其中 Playwright 浏览器测试不包含在 `npm run verify` 内，需要单独执行最后一条命令。
