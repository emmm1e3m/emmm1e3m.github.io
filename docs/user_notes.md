# 旅行饼狗使用说明

## v0.10.1 的核心规则

- 新开始的旅行、刷播、冲热、弹琴和睡觉默认读条均为 10 秒，开始前会在右侧信息栏二次确认。
- 五类饼屋活动每成功领取一次，或苹果钟完成专注与休息整轮，陪伴天数增加一天。提前取消、重复检查、普通现实停留结算和待办操作不会进入下一天；活动取消也不会返还已经消耗的补给或幸运苹果。
- 睡觉完成后不奖励🍎，只刷新饼狗的活动意愿、播放日夜转场并推进游戏日。迁移到 V11 时，旧档中仍在进行或已完成待领取的睡觉也会统一改为 0🍎。
- 今日 Bingo 三项全部完成后会以 `√` 保留，等下一次游戏日（陪伴日）推进时再刷新；任一任务尚未完成，则跨游戏日继承原任务与完成状态。成功领取任一种饼屋活动，或完成一轮完整苹果钟，都会推进一个游戏日。
- 新签发的每条日常任务最多奖励 3🍎；旧存档里已经签发的任务仍按自己的奖励快照结算。
- 新任务会先检查当前收藏是否足以完成：没有对应收藏时不会出现“重看明信片”“重看百万瞬间”或“重看全站第一”，少于两份有效收藏时不会要求重温两份回忆。读取缓存/本地存档或在 DEBUG 中移除收藏后，已经无法完成但结构合法的未完成任务会稳定换成可完成任务；已完成任务和仍可完成任务的进度不变，损坏或篡改的任务板仍会被拒绝。
- 与饼狗完成有效互动后的提示统一为“互动完成”。
- 两款游戏字体已扩展为 2500 个标准常用汉字加当前界面表外用字；以后输入或新增普通常用汉字文案时，不会再因为旧字体只含当时页面字符而突然回退到系统字体。界面分为三级文字层级：可画乐融融用于标题、强调、HUD 和苹果数字，可画奶糖体用于正文、说明与表单，辅助信息沿用奶糖体并使用较小字号。
- 存档会记录正在进行的活动及其绝对开始、结束时间和奖励计划。即使以后再次修改默认时长，旧任务仍按开始时写入的时间完成；除睡觉奖励在 V10→V11 迁移时归零外，其他活动仍保留开始时的奖励快照。
- 饼狗对旅行、电脑和音乐分别有自己的意愿；刷播与冲热共享电脑意愿。它不想做的入口会变暗，点击只显示原因，不会偷偷开始或扣资源。
- 点击房间空白会显示当前任务和饼狗兴趣概览。活动中左下 `↩️` 会打开真正的取消确认，右上 `ℹ️` 打开当前维度说明，右下 `🔃` 会先介绍并确认再切换维度。
- 顶部状态栏会把页面入口与运行状态分别向左右分组；现实计时、活力、🍎、收藏墙和 DEBUG 状态都可点击进入对应页面或操作。饼狗状态统一显示为低活力、中等活力、高活力或活力满满，不再显示“状态正常”。启动刷播后，状态栏会显示启动中、运行中或停止中，点击可打开或切回在线刷播工具；轮次、倒计时和记录仍只在独立工具中查看。桌面端房间在左、信息区在右；宽度不超过 960px 时房间固定在上、信息区在下，不会再由信息区覆盖房间。

## 冰箱与两种魔法

冰箱共有七种带 emoji 的道具，金额统一显示为 `N🍎`：

- 🍱普通旅行便当、🍎苹果旅行便当、🎧信号耳机、🧰热度工具箱和 🍀幸运苹果；
- ⚡瓶装速度魔法：读条仍在进行时可消耗一瓶，让这次活动立刻进入可领取状态；
- ✨瓶装活力魔法：让饼狗接下来七个相伴日对旅行、电脑和音乐都有兴趣。

瓶装速度魔法单价为 2🍎，瓶装活力魔法单价为 7🍎。🍎苹果旅行便当让当次旅行遇友概率翻倍；🍀幸运苹果让当次对应收藏概率翻倍。两者分别作用于自己的目标概率，同类加成只取最高值，不会继续复合叠加。

七个相伴日会由成功领取饼屋活动或完成苹果钟推进，不是七个自然日。苹果钟推进到第七天时，活力效果结束并恢复饼狗当日偏好。魔法不需要时不会被消耗。

## 收藏与好朋友

- 明信片和百万直拍随机从未拥有项中选择，不会重复；百万直拍基础概率为 30%，使用幸运苹果后为 60%。全站第一基础概率为 15%，按 Dynamite → Talk WORTHY? Talk DIRTY! → Make A Wish → Dawn in my soul → 愿与愁 → 囍 → Hey Mama → POWER 的时间顺序获得。幸运苹果的结果等于 `min(100%, 基础概率 + 基础概率)`，不会基于已经增强过的概率再次翻倍。
- 旅行以 10% 基础概率遇见朋友，苹果旅行便当让当次概率变为 20%；命中时不会同时得到明信片，并收到固定道具。课代饼、三好兔、心好兔、信号狗、饼哩饼哩在旅行中依次赠送 2/3/4/3/2🍎；已经认识的朋友仍可再次遇见并照常赠礼。弹琴只会召回已经认识的朋友，不会凭空解锁新朋友；每位已认识朋友增加 15% 来访概率，五位朋友依次赠送 4/6/8/6/4🍎，所以认识的朋友越多，每次弹琴的期望赠礼越高。
- 收藏墙只展示已经获得的明信片、百万直拍、全站第一和好友。没有内容时显示“惊喜会在相遇时悄悄出现。”
- 收藏墙标题和已经出现的分类显示拥有进度；未集齐前隐藏总数，例如“好朋友们【4/?】”，全部集齐后显示“【5/5】”。总数来自当前内容目录，不写入存档。
- 卡片缩略图可以铺满裁切；收藏详情、全屏预览和明信片选择器会以 `contain` 完整显示并允许留白，苹果钟运行背景则以 `cover` 铺满并允许裁切。在详情中点击收藏图片，可以全屏查看并下载到本地；百万直拍和全站第一的海报窗口会按原图真实比例自适应，完整显示且不留白、不裁切。
- DEBUG 的“一键全收集”会一次获得全部收藏、好友和 24 件衣服，并让已无可售款式的商店变空；“清空收集”会清空收藏、好友与当前保存的造型，把衣服恢复到初始赠送披肩，并在同一游戏日按 `min(3, remaining)` 规则重建商店（当前目录下会显示 3 件）。历史合拍保留拍摄时的轻量造型快照，只把已经失效的明信片背景移除。无需维护专用全收集存档。

存档不写死当前收藏或好友总数，也不保存分类解锁状态。以后增加内容时，旧存档会把新增 ID 视为尚未获得的内容。

## 房间、电子琴与播放器

- 房间严格使用用户提供的 1098 × 1433 透明原图，网页不重绘、不拉伸、不裁切，只生成等比无损 WebP，并以 `contain` 完整显示；宽屏横向房间区域允许保留透明侧边留白。饼狗在床、两台电脑、衣架、电子琴、冰箱、唱片机、收藏墙和房门的位置都按原图像素坐标锁定。
- 电子琴有 C3–B6 四个完整八度，共 48 个半音，从上到下显示 C6、C5、C4、C3。鼠标、触摸可以弹全部琴键；物理键盘白键从高到低依次映射 `1–7`、`Q–U`、`A–J`、`Z–M`。
- 唱片机固定提供八首全站第一，从 Dynamite 到 POWER 按时间顺序排列，不提供自定义曲库。列表、单曲和随机模式都可使用上一首、下一首；单曲模式下主动切歌仍会移动到相邻曲目。
- 唱片机与收藏详情共用一个持久播放器。选曲或打开视频详情会从头请求自动播放；画面展开时可直接操作 B 站播放器，收起后画面不可操作，也可用游戏控件显示/隐藏画面、暂停/继续或取消播放。若直接在 B 站画面里暂停或拖动，游戏无法读取这个跨站变化，估算计时不会同步；切换信息内容、收藏墙或维度后不会意外中断。
- 存档只记住当前曲目和循环模式；重新打开页面不会恢复正在播放的进度。

## 奇迹饼狗

- 点击衣架会先看到房间里的衣架信息菜单：每个游戏日开始时，从当时尚未拥有的可售款式中抽取最多 3 件；剩余不少于 3 件时展示 3 件，不足时全部展示，全部收集后为空。商品使用真实透明缩略图，购买金额、余额不足和禁用状态与冰箱保持同一种样式；买下后立即从当天菜单消失且不补位。没有可买商品时不显示“今天仍可购买”标题。菜单另有“进入奇迹饼狗”和“打开独立舞台测试”两个入口。当前共有 24 件服装与配饰，一件基础披肩随新存档获得，其余价格平均约 5🍎。“衣服收藏”按套装、头饰、面饰、配饰和道具分类完整展示素材，不再放大裁切边缘。
- 奇迹饼狗采用紧凑全屏布局，头部、页签和状态保持可见，当前面板使用剩余高度。桌面搭配室分为角色与造型、画布、服装与调整三栏；合拍分为角色与明信片、画布、贴纸与调整三栏。画布、图层和调整按钮保持在视口内，较长的造型、服装/贴纸列表及明信片弹窗单独滚动。窄屏按同一顺序改为单列，由当前面板统一纵向滚动。可以为饼狗和已经认识的朋友分别搭配，并给同一角色保存最多 8 套造型。
- 搭配画布里的角色与服装构成同一个组合层，整体约占画布的 38%，因此角色缩小后服装和配饰仍会保持相对位置。已拥有素材可以按分类筛选，画布图层排在素材选择器上方。选中元素后，同一行的 🔼、🔽、🔄️、❌ 分别表示前移、后移、恢复默认变换和移除，并带有完整的无障碍名称；画布中心和两个角落手柄继续用于移动、双轴缩放与旋转。保存后只记录素材及 `x/y/scaleX/scaleY/rotation/z`，不会把整张合成图片塞进存档；当前角色也可以下载透明背景 PNG。
- “一起合拍”复用苹果钟的明信片选择弹窗，只能从已经收藏的明信片中单击选择背景，不提供白纸或历史合拍。画布跟随明信片真实长宽比，完整铺满背景而不加灰色遮罩；每张合拍选择 1–6 位可用角色，已认识的朋友可以单独出镜。照片图层位于独立元素选择器上方，并复用同一行的四个图标操作。照片还可添加最多 12 个独立装饰；装饰属于整张照片而非人物，并与人物共享照片级遮挡顺序。保存后会进入奇迹相册，可以删除或下载 PNG；旧合拍保留拍摄当时的搭配快照，不会跟着后来换装改变。
- 原来的舞台测试仍由衣架信息菜单独立打开，不属于奇迹饼狗页。海星体、完整套装与配饰是依据本地参考图经 ImageGen 重画的同源透明素材；素材构建会清除纯蓝幕、柔化相邻蓝边，同时保留色键范围外的服装蓝色细节，并避免把相邻格素材碎片带入当前元素。

## 现实生活维度

电脑端与移动端都可以通过房间右下角进入现实维度：

- 二楼电脑拆分为“刷播”和“冲热（开发中）”；冲热目前仅在电脑端开放，冲热页提供居中的“前往字母建设站”入口。
- 刷播现在只有一种方式：使用说明、设备检查和时长提醒会合并在一个分点提示框中；在游戏里选择“刷播”或“测试”收藏夹，填写一个可选自测视频 BV 号/完整视频链接和定时停止时长，再打开名为 `SUperView` 的独立竖屏窗口。窗口中的页面名为“在线刷播工具”，也可以修改这些参数后手动开始。主游戏和独立工具都会提示：请在网页版哔哩哔哩设置“自动开播”和“播完暂停”。启动刷播窗口后，返回游戏维度也可以继续；移动端离开刷播页面可能会导致刷播暂停。
- 在新设备/浏览器上请先检查：若登录，历史记录里出现刷播视频为成功；若未登录，自测视频播放量增加为成功。请允许本站弹出窗口。刷播会使用当前浏览器账号；登录时每天不要超过 5 小时。定时停止为 0 或留空时不限时，最长 24 小时。
- 两份收藏夹清单随游戏发布：`3682220021` 是刷播收藏夹，`3986840044` 是测试收藏夹。网页只读取本站同源 TXT，不会在游玩时请求 B 站收藏夹接口，也不使用跨域代理。
- 每轮都会重新随机排列所选收藏夹，自测视频固定在末尾。在线刷播工具每隔 5 秒创建一个静音、自动播放且从头开始的官方播放器；最后一个播放器创建后按实际时间等待默认 310 秒，再统一销毁本轮播放器并开始下一轮。页面仍存在但从后台冻结中恢复时，会按绝对截止时间校准，不靠每秒累加的计数器；关闭独立页会停止本页刷播。
- 在线刷播工具打开后会始终用一段低音量音频尽量保持页面活跃，停止任务也不会暂停它。点击大标题 5 次、输入密码 `SUperView` 可解锁自己的 DEBUG；开启状态会保存在该页面，重开时无需再次输入密码，也可以用“关闭 DEBUG”清除这个状态。DEBUG 可修改轮次间隔并选择显示播放器；未开 DEBUG 时播放器只是隐藏，仍会实际创建。主游戏 DEBUG 不会改变刷播页的轮次间隔。
- 第一次真正启动在线刷播工具可得 20🍎。点击开始或弹窗成功都不会领奖；只有独立页完成准备并发出受信 `started` 后，主游戏才以语义有效的本地 `YYYY-MM-DD` 领取。已经领奖的最大本地日期会被保留；同日或早于该日期都不会重复发放，只有更晚的现实日期首次 `started` 才能再次领取。
- 主游戏状态栏只显示刷播启动中、运行中或停止中，点击可打开或切回在线刷播工具；它不显示轮次、下一轮倒计时或运行记录，也不会向游戏存档中的旧 `streamHistory` 写入新数据。完整状态和最近 10 次任务只在在线刷播工具中显示并由它自行保存；每日 `started` 与奖励领取不属于这类统计。一次启动包含多轮也只记一条：每完成一轮便用同一 `sessionId` 更新当前 checkpoint，正常停止再覆盖为 final，`pagehide` 只作兜底，因此硬关闭至少会保留上一完整轮。官方播放器页面会按浏览器策略使用当前可用于 B 站的 Cookie，并由 B 站自行发送媒体、统计和心跳请求；本站不能读取播放器内部、Cookie 或网络响应，也无法保证真实播放与计数结果。
- 一楼电脑“工作”先显示待办，再显示背景选择器；可以选择已解锁明信片或已经保存的奇迹合拍。苹果钟提供 25+5、50+10、90+15 三组专注与休息周期。
- 苹果钟启动后把选定明信片或动态重建的奇迹合拍作为 `cover` 全屏背景；专注动画里的饼狗使用坐在电脑前的刷播姿态，不再使用睡觉姿态。界面还会展示待办和可操作的游戏播放器控件；完成专注与休息整轮才增加一天陪伴天数。允许通知后，阶段结束会请求系统提醒；若通知不可用或未授权，会使用页内提示。
- 每在现实维度实际打开旅程满 10 分钟，结算基数增加 1🍎。状态栏只显示已累计分钟，点击等同于返回游戏维度。页面每 60 秒把已累计时间写入缓存；点“离开”、离开旅程或触发 `pagehide` 会立即暂停，异常退出最多累计到最后一次心跳。再次继续缓存时只从已累计值接着计时，不补离线时段。未攒到 1🍎时直接返回饼屋，不弹出完成确认；达到 1🍎后，选择“是的🥰”获得全额，选择“没有🥺”获得向下取整的一半。

## 存档兼容与浏览器限制

- 浏览器缓存是日常主存档。标题页在存在缓存时显示“继续”，并始终提供“全新旅程”和“本地存档”；`.bingo` 文件用于备份和跨浏览器导入。
- 通过“全新旅程”或“本地存档”覆盖缓存之前、检测到网页更新时都会先下载旧档；首次获得新的全站第一或认识新朋友时会下载关键节点存档，每隔三天也会请求一次备份。
- 当前产品版本为 `v0.10.1`；新存档使用 `schemaVersion: 12` 与 `gameVersion: 0.10.1`，读取时严格支持 V1–V12。系统先校验原文件摘要，再逐代迁移和核对当前目录，不会先改文件再验摘要。
- 旧缓存成功迁移或协调后，会同步写回 V12 进度、当前游戏版本与缓存更新时间；缓存外层格式版本不随业务存档版本改变。V10 已冻结为迁移历史，V10→V11 按原存档种子和当前游戏日初始化衣柜，并把尚未领取的旧睡觉奖励归零，其他活动快照保持不变。V11 也保持冻结，再由显式 V11→V12 迁移把旧单轴缩放复制到相等双轴、给旧照片补空装饰，把苹果钟明信片 ID 变成背景引用，并初始化空的每日刷播奖励日期。
- V12 存档包含当前活动、两种魔法、现实停留租约与待结算奖励、待办、完整苹果钟、播放器设置、单个可选自测 BV、所选收藏夹、最近每日刷播奖励日期、已购服装、每日商店、多套角色造型、双轴合拍构图与独立照片装饰；旧版刷播兼容字段仍冻结保留，但不会写入独立页的新轮次/会话记录、刷播清单、运行中的 iframe、定时器、保活音频、DEBUG 页面设置或完整合成图。
- 标题页在两个圆形头像下方、缓存记录上方展示 `v0.10.1` 更新公告；卡片右侧的版本胶囊位于原日期上方，不再混入正文。房间左上角的 `#️⃣` 也会打开同一公告。公告明确说明“刷播现在可以正常使用了”，并介绍奇迹饼狗、多套造型与合拍相册。首次进入或从旅程返回标题页时各自动检查一次更新，同一次停留不会重复检查，按钮仍可手动再查；检测到新版本时会自动备份缓存进度，再提供更新安装。
- 守候音频只在进入旅程的用户手势后启动并保持开启，不在状态栏显示开关。它只能尽量减少浏览器休眠，不能绕过系统节能和后台冻结。
- 移动设备以触屏为主时，游戏会在旅程运行且页面可见期间请求屏幕常亮；隐藏页面会释放，重新显示时再请求。不支持或拒绝常亮权限不会影响继续游玩。
- 系统通知需要用户主动授权。页面完全关闭、浏览器被冻结或设备休眠时，不保证准时弹出；返回页面后会按绝对时间补检查。

## 本地启动与验证

Windows 下双击仓库根目录的 `启动旅行饼狗.cmd`，或运行：

```powershell
npm ci
npm run dev -- --host localhost --port 5173 --strictPort --open "/AllForSUXINHAO/TravellingBingo/"
```

完整本地门禁：

```powershell
npm run verify
npm run build
npm run site:assemble
npm run site:verify
npm run test:e2e
```

其中 Playwright 浏览器测试不包含在 `npm run verify` 内，需要单独执行最后一条命令。
