# 旅行饼狗使用说明

## V5 的核心规则

- 新开始的旅行、刷播、冲热、弹琴和睡觉默认读条均为 10 秒，开始前会在右侧信息栏二次确认。
- 五类饼屋活动每成功领取一次，或苹果钟完成专注与休息整轮，陪伴天数增加一天。提前取消、重复检查、普通现实停留结算和待办操作不会进入下一天；活动取消也不会返还已经消耗的补给或幸运苹果。
- 存档会记录正在进行的活动及其绝对开始、结束时间和奖励计划。即使以后再次修改默认时长，旧任务仍按开始时写入的时间完成。
- 饼狗对旅行、电脑和音乐分别有自己的意愿；刷播与冲热共享电脑意愿。它不想做的入口会变暗，点击只显示原因，不会偷偷开始或扣资源。
- 点击房间空白会显示当前任务和饼狗兴趣概览。活动中左下 `↩️` 会打开真正的取消确认，右上 `ℹ️` 打开当前维度说明，右下 `🔃` 会先介绍并确认再切换维度。

## 冰箱与两种魔法

冰箱共有七种带 emoji 的道具，金额统一显示为 `N🍎`：

- 🍱普通旅行便当、🍎苹果旅行便当、🎧信号耳机、🧰热度工具箱和 🍀幸运苹果；
- ⚡瓶装速度魔法：读条仍在进行时可消耗一瓶，让这次活动立刻进入可领取状态；
- ✨瓶装活力魔法：让饼狗接下来七个相伴日对旅行、电脑和音乐都有兴趣。

瓶装速度魔法单价为 3🍎；幸运苹果会把对应收藏事项的目标概率提高 10 个百分点。

七个相伴日会由成功领取饼屋活动或完成苹果钟推进，不是七个自然日。苹果钟推进到第七天时，活力效果结束并恢复饼狗当日偏好。魔法不需要时不会被消耗。

## 收藏与好朋友

- 明信片和百万直拍随机从未拥有项中选择，不会重复；全站第一按 Dynamite → Talk WORTHY? Talk DIRTY! → Make A Wish → Dawn in my soul → 愿与愁 → 囍 → Hey Mama → POWER 的时间顺序获得。
- 旅行遇见朋友时不会同时得到明信片。弹琴只会召回已经认识的朋友，不会凭空解锁新朋友。
- 收藏墙只展示已经获得的明信片、百万直拍、全站第一和好友。没有内容时显示“惊喜会在相遇时悄悄出现。”
- 缩略图与详情图会铺满裁切；在详情中点击图片，可以进入完整比例的全屏查看并下载到本地。
- DEBUG 的“一键全收集”包含好友，“清空收集”会同时清空收藏与好友记录；无需维护专用全收集存档。

存档不写死当前收藏或好友总数，也不保存分类解锁状态。以后增加内容时，旧存档会把新增 ID 视为尚未获得的内容。

## 房间、电子琴与播放器

- 房间严格使用用户提供的 1098 × 1433 透明原图，网页不重绘、不裁切，只生成等比无损 WebP。饼狗在床、两台电脑、衣架、电子琴、冰箱、唱片机、收藏墙和房门的位置都按原图像素坐标锁定。
- 电子琴有 C3–B6 四个完整八度，共 48 个半音，从上到下显示 C6、C5、C4、C3。鼠标、触摸可以弹全部琴键；物理键盘白键从高到低依次映射 `1–7`、`Q–U`、`A–J`、`Z–M`。
- 唱片机与收藏详情共用一个持久播放器。选曲或打开视频详情会立即向 B 站播放器请求自动播放；切换信息内容或维度后 iframe 仍保留，也可以明确停止播放。
- 唱片机默认提供当前最新七项全站第一（Talk WORTHY? Talk DIRTY! 至 POWER），也可切换到自己的播放列表。输入列表名称，再按一行一个填写 BV 号或完整 Bilibili 视频链接，即可创建或更新曲库；重复 BV 会自动去重。
- 播放器保存当前 BV、播放列表和列表/单曲/随机模式。单曲模式下手动上一首、下一首仍会正常切歌；已知时长的视频会尽力在结束后续播。

## 现实生活维度

PC 浏览器可通过房间右下角切换维度；手机、平板等没有精细指针能力的浏览器不能进入现实维度：

- 二楼电脑“数据”直接显示刷播与冲热，并提供“前往”运行组入口。
- 一楼电脑“工作”先显示待办，再显示已解锁明信片选择器。苹果钟提供 25+5、50+10、90+15 三组专注与休息周期。
- 苹果钟启动后全屏展示选定明信片、陪伴饼狗、待办和可交互播放器；完成专注与休息整轮才增加一天陪伴天数。允许通知后，阶段结束会请求系统提醒；若通知不可用或未授权，会使用页内提示。
- 每在现实维度停留完整 10 分钟，结算基数增加 1🍎。返回游戏时，选择“是的🥰”获得全额，选择“没有🥺”获得向下取整的一半；现实停留结算和待办操作本身都不增加陪伴天数。

## 存档兼容与浏览器限制

- 浏览器缓存是日常主存档。标题页固定提供“新存档”“从缓存存档继续”“加载本地存档”三个入口，`.bingo` 文件用于备份和跨浏览器导入。
- 通过“新存档”或“加载本地存档”覆盖缓存之前、检测到网页更新时都会先下载旧档；首次获得新的全站第一或认识新朋友时会下载关键节点存档，每隔三天也会请求一次备份。
- 新存档为 V5；读取时严格支持 V1–V5。系统先校验原文件摘要，再迁移和核对当前目录，不会先改文件再验摘要。
- V5 存档包含当前活动、两种魔法、现实停留与待结算奖励、待办、完整苹果钟和播放器设置；不会复制海报、视频元数据或收藏目录总数。
- “检查新布置”只保留在标题页，检查结果是临时提示；检测到新版本时会自动备份缓存进度，再提供更新安装。
- 守候音频只在进入旅程的用户手势后启动并保持开启，不在状态栏显示开关。它只能尽量减少浏览器休眠，不能绕过系统节能和后台冻结。
- 系统通知需要用户主动授权。页面完全关闭、浏览器被冻结或设备休眠时，不保证准时弹出；返回页面后会按绝对时间补检查。
- GitHub Pages 无法稳定直取需要 B 站 Referer 且会过期的签名视频流，因此当前使用官方 iframe；有声自动播放仍受浏览器与第三方播放器策略约束，已知时长的视频只做尽力续播。

## 本地启动与验证

Windows 下双击仓库根目录的 `启动旅行饼狗.cmd`，或运行：

```powershell
npm ci
npm run dev -- --host localhost --port 5173 --strictPort --open "/AllForSUXINHAO/TravellingBingo/"
```

完整本地门禁：

```powershell
npm run verify
npm run build
npm run site:assemble
npm run site:verify
npm run test:e2e
```

其中 Playwright 浏览器测试不包含在 `npm run verify` 内，需要单独执行最后一条命令。
